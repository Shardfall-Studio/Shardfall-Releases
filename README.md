# Shardfall — downloads

Shardfall is a painterly fantasy MMO-lite: start in the town of Millbrook, take quests and bounties out into the wilds, and earn cloth, leather and plate gear and weapons for every class. You can play solo (Play hosts a local game) or with friends.

This repository only hosts the game's releases; it has no source code.

## Play on Windows
1. Download **[ShardfallLauncher.exe](https://github.com/Shardfall-Studio/Shardfall-Releases/releases/latest/download/ShardfallLauncher.exe)** and put it in its own folder (for example `C:\Games\Shardfall`).
2. Run it. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway** (the launcher is not code-signed yet).
3. The launcher downloads and installs the game (about 420 MB), checks it, and keeps it updated. Click **PLAY** when it says Ready.

Linux: [ShardfallLauncher.x86_64](https://github.com/Shardfall-Studio/Shardfall-Releases/releases/latest/download/ShardfallLauncher.x86_64) (`chmod +x` it, then run it).

All files are on the [Releases page](https://github.com/Shardfall-Studio/Shardfall-Releases/releases).
